# Healthcare Market Research & Consumer Segmentation

An R-based machine learning project that performs Exploratory Data Analysis (EDA) and K-Means clustering to segment healthcare consumers based on demographics and spending habits.

## 🚀 Tech Stack
* **Language:** R
* **Libraries:** `tidyverse`, `ggplot2`
* **Algorithm:** Unsupervised Machine Learning (K-Means Clustering)

## 📊 Project Workflow
1. **Data Simulation / Ingestion:** Generated a structured healthcare consumer dataset across multiple variables (Age, Annual Income, Health Consciousness Score, and Annual Healthcare Spend).
2. **Exploratory Data Analysis (EDA):** Computed correlation matrices to identify relationships between financial metrics and healthcare habits.
3. **Market Segmentation:** Standardized consumer features and applied K-Means clustering to group consumers into 3 distinct behavioral cohorts.
4. **Data Visualization:** Built color-coded scatter plots using `ggplot2` to visualize income versus healthcare expenditure clusters.

## 💡 Key Insights & Visualization
Successfully categorized consumers into distinct market segments to help healthcare organizations optimize targeting and marketing strategies.
